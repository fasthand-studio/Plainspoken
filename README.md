# Plainspoken

### A design system by Fasthand Studio.

Plainspoken is a design system built around 25 rules for creating consistent user interfaces. It brings together the visual and functional details of UI design, including typography, spacing, color, geometry, layout, and interaction.

**Website:** https://plainspoken.fasthandstudio.asia/

---

## Overview

The project is divided into two sections: **Rulebook** and **Lab**.

The Rulebook documents the 25 design rules, providing a reference for making consistent decisions throughout the design and development process.

The Lab takes those ideas further through interactive examples, making it possible to explore and experiment with different design choices.

## The Rulebook

The rules cover the fundamentals of interface design, from how text is presented and how elements are spaced to how components are shaped and how colors are used.

Each rule addresses a particular part of the interface, with an emphasis on consistency, readability, and practical application.

## The Lab

The Lab is where the design rules become interactive. It provides a visual way to explore the concepts behind Plainspoken rather than relying entirely on written explanations.

## About

Plainspoken is created and maintained by **Fasthand Studio** as a design reference for building its digital products. It is also intended to be useful beyond the studio for anyone working with UI design and frontend development.
